12 dimensions analysées par l'IA

Pour chaque utilisateur virtuel (agent) et chaque événement, l'IA examine simultanément 12 caractéristiques :

Profil de l'agent
  • Type : étudiant, pro, curieux, expert
  • Budget disponible (50€ – 800€)
  • Sensibilité au prix (0-1)
  • Spontanéité (0-1)
  • Loyauté (0-1)

Caractéristiques de l'événement
  • Prix (gratuit – 500€)

  • Catégorie (tech, business, etc.)

Apprentissage supervisé : comment l'IA s'améliore
1
Collecte de données réelles

Le système enregistre les véritables choix des utilisateurs (inscriptions, clics, favoris). Chaque interaction devient un exemple d'entraînement.

📝 Exemple : "Un étudiant avec budget 80€ a choisi l'atelier gratuit le mardi à 14h"
2
Feed-forward (propagation avant)

Le réseau calcule une prédiction à partir des caractéristiques. Au début, les prédictions sont aléatoires.

3
Calcul de l'erreur (Loss)

On compare la prédiction avec la réalité : Erreur = (Prédiction - Réalité)²

🎯 Si l'IA prédisait 30% mais l'utilisateur a choisi → Erreur = (0.3 - 1)² = 0.49
4
Rétro-propagation (Backpropagation)

L'erreur est propagée vers l'arrière à travers toutes les couches. Chaque neurone reçoit sa "part de responsabilité".

5
Descente de gradient

Les 3 457 poids sont légèrement ajustés pour réduire l'erreur la prochaine fois. C'est comme apprendre d'une erreur pour ne pas la répéter.

📉 Nouveau poids = Ancien poids - 0.001 × Dérivée de l'erreur
6
Répétition (Époques)

Le processus est répété 30 à 50 fois sur l'ensemble des données. À chaque époque, la précision du modèle augmente.

💡
Exemple concret de prédiction
🤖 Agent : Étudiant, budget 120€, sensible au prix (0.8), spontané (0.4)
🎯 Événement : Workshop Tech, 50€, populaire (places limitées)
1. Normalisation : Budget → 0.12, Prix → 0.1, Popularité → 0.85, ...
2. Entrée X : [0.8, 0.12, 0.8, 0.4, 0.5, 0.1, 0.6, 0.85, 0.08, 0.4, 0.57, 0.58]
3. Propagation : X → Couche1 (64) → ReLU → Couche2 (32) → ReLU → Couche3 (16) → ReLU → Sortie (1)
4. Probabilité finale : 78.3% → L'agent va probablement s'inscrire
